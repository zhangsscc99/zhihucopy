# DESIGN — zhihucopy 视觉语言

> 方向：**中文知识社区**。干净、克制、以阅读为核心；排版优先于装饰。
> 不做：暗色霓虹、SaaS 圆角卡片套件、渐变装饰。

## 1. 色板（design tokens）

| token | hex | 用途 |
|---|---|---|
| `--paper` | `#F6F7F8` | 页面底色（冷灰白，阅读纸面） |
| `--surface` | `#FFFFFF` | 内容承载面（正文、侧栏） |
| `--ink` | `#1B1E23` | 主文字（墨色） |
| `--ink-2` | `#59616B` | 次级文字（元信息、说明） |
| `--line` | `#E3E6EA` | 发丝线分隔（不用阴影分区） |
| `--accent` | `#1F4EA1` | 链接/主按钮（深书卷蓝，正文上对比度 ≈8:1） |
| `--seal` | `#B03A2E` | 朱砂印章红——**只用于** logo 印章与热榜前三名序号 |

规则：蓝色承担交互，朱砂红承担「印记」。其它元素一律墨色阶。

## 2. 字体分工

- **阅读/标题**：`"Noto Serif SC", "Source Han Serif SC", "Songti SC", "SimSun", serif`
  问题标题、回答正文、logo、大数字——衬线承载「书卷气」，是本站的性格所在。
- **界面/元信息**：`-apple-system, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Noto Sans SC", sans-serif`
  导航、按钮、表单、时间/计数等元信息——无衬线保证小字号清晰。
- 正文 16px / line-height 1.75；行长 ≤ 44 汉字；标题用字重与字号区分层级，不用变色单词、不用全大写标签。

## 3. 布局

桌面（≤1200px 内容区，居中）：

```
┌──────────────────────────────────────────────────────┐
│ 知乎（仿）[ 搜索____________ ]        [提问]  (头像▾)   │ ← 顶栏，底部发丝线
├───────────────────────────────┬──────────────────────┤
│  关注 | 推荐 | 热榜  (tab)     │  热榜                 │
│  ─────────────────────────    │   1 标题…             │
│  问题卡片：标题 + 摘要 + 元信息  │   2 标题…   (前3朱砂) │
│  （发丝线分隔，非阴影卡片）      │                       │
│                               │  页脚链接              │
└───────────────────────────────┴──────────────────────┘
   main 694px                    rail 296px，gap 30px
```

- 问题详情页：主栏 = 标题（衬线大号）→ 话题 tag → 详情 → 回答列表（发丝线分隔）；侧栏 = 关注问题按钮 + 相关问题。
- 移动端（<768px）：单栏；底部导航（首页/热榜/发布/通知/我）。
- 全部左对齐；正文不居中、不两端对齐。

## 4. 原则

1. **阅读优先**：最大视觉预算给正文排版；装饰一律让位。
2. **发丝线而非卡片**：内容区用 `1px --line` 分隔，不用圆角阴影盒子切碎信息流。
3. **红只出现一次**：同一屏内朱砂红只服务于「印章/榜首」一个语义。
4. **元信息退后**：时间、计数、作者用 `--ink-2`、13px，不抢正文。
5. **动效只回应操作**：hover/焦点/提交反馈；无入场动画、无滚动特效；尊重 `prefers-reduced-motion`。
6. **文案说人话**：按钮写动作（"发布回答"），错误写原因与下一步。

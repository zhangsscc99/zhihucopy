# DESIGN — zhihucopy 视觉语言

> 方向：**知乎仿站**。白卡、细边框、知乎蓝主色、灰阶文字层级、高信息密度。
> 不做：暗色霓虹、游戏风、渐变装饰、SaaS 大圆角、重阴影、衬线书卷气。

## 1. 色板（design tokens）

| token | hex | 用途 |
|---|---|---|
| `--paper` | `#F6F6F6` | 页面底色（知乎浅灰，禁止纯白页底） |
| `--surface` | `#FFFFFF` | 内容承载面（卡片、信息流、侧栏、顶栏） |
| `--ink` | `#121212` | 主文字（标题、正文） |
| `--ink-2` | `#444444` | 次级文字（摘要、正文辅助） |
| `--ink-3` | `#8590A6` | 元信息（时间、计数、话题胶囊字色） |
| `--line` | `#EBEBEB` | 卡片细边框与分隔线 |
| `--accent` | `#0066FF` | 知乎蓝：链接、主按钮、赞同、激活态（hover `#005CE6`） |
| `--hot-1` / `--hot-23` | `#FF5A5F` / `#FF7A45` | 热榜第 1 名 / 第 2–3 名序号色 |
| `--radius` | `3px` | 全局圆角（卡片、按钮、输入框、胶囊统一） |

规则：蓝色承担全部交互语义；灰阶承担信息层级；红橙色仅出现在热榜前三名序号与错误态。

## 2. 字体分工

- **全站统一系统中文无衬线**：
  `-apple-system, BlinkMacSystemFont, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", "Helvetica Neue", Arial, sans-serif`
  正文、标题、logo、数字、界面元素一律同族，靠字重与字号分层。
- 正文 15px / line-height 1.7；正文与公告行宽 ≤ 700px。
- 问题标题 18px / 700 / `#121212`；摘要两行截断；元信息 13px `#8590A6`。
- 话题胶囊：灰底 `#F6F6F6`、字色 `#8590A6`、12px、高 24px、圆角 3px。

## 3. 布局

桌面（≤1020px 内容区，居中）：

```
┌──────────────────────────────────────────────────────────┐
│ 知乎   [      居中搜索框（灰底圆角）      ]   [提问] (▾)  │ ← 顶栏 sticky，白底，底部 1px 线，高 52px
├─────────────────────────────────┬────────────────────────┤
│  推荐 | 热榜  (tab)              │  热榜                   │
│  ────────────────────────────   │   1 标题…  (橙红)       │
│  信息流卡：18px 标题              │   2 标题…  (橙)         │
│   + 摘要（两行截断）              │   4 标题…  (灰)         │
│   + 13px 灰元信息                │                        │
│  （白卡 + 1px 细边框，无阴影）     │  页脚链接               │
└─────────────────────────────────┴────────────────────────┘
   main 694px                       rail 296px，gap 10px
```

- 顶栏：`position: sticky; top: 0`，白底 + 底部 `1px --line`；搜索框 `flex:1; max-width:520px; margin:0 auto` 居中，灰底 `#F6F6F6`、无边框、聚焦白底蓝边；右侧 `.topnav__actions` 放蓝色实心「提问」按钮。
- 问题详情页：主栏 = 话题胶囊 → 标题（22px/700）→ 详情 → 回答列表（发丝线分隔）；侧栏 = 关注按钮 + 热榜。
- 移动端（<768px）：单栏；底部导航（首页/热榜/发布/通知/我）。
- 全部左对齐；正文不居中、不两端对齐。

## 4. 原则

1. **像知乎**：蓝主色 `#0066FF`、灰阶三级文字、白卡细边框、圆角 3px、无重阴影、信息密度高。
2. **细边框而非阴影**：分区只用 `1px --line`；至多允许 `0 1px 3px rgba(18,24,35,.04)` 级别的极浅投影。
3. **灰阶层级**：正文 `#121212`、次要 `#444444`、元信息 `#8590A6`，层级靠灰度不靠花哨颜色。
4. **截断保持密度**：摘要 `-webkit-line-clamp: 2` 两行截断，列表保持节奏。
5. **动效只回应操作**：hover 只改颜色/边框，不浮起；无入场动画；尊重 `prefers-reduced-motion`。
6. **文案说人话**：按钮写动作（"发布回答"），错误写原因与下一步。

### 二、缺陷清单

#### P0-1 回答卡片没有「赞同/点赞」按钮，点赞链路完全不存在
- **现象**：`/question/1` 有 3 条回答，每条只有「229 人赞同」纯文本计数，卡片内没有可点元素（`button` 数=0、`a` 数=1 仅作者链接）。整页 `main` 内 button 数为 0。点赞无从谈起，计数 +1、状态变蓝都无法验证。
- **复现步骤**：`/zhihucopy/question/1` → 查看任一回答卡片底部 → 找不到赞同/反对按钮；接口层 `POST /api/votes {target_type:"answer",target_id:2,value:1}` 实测返回 `{"vote":1,"voteup_count":230}`，说明后端已就绪，前端未接入。
- **期望**：知乎式「▲ 赞同 230 / ▼」按钮，点击后计数 +1 且按钮文字变蓝，再点取消回退；未登录点击引导登录。
- **严重度**：P0（阻断主流程）
- **截图**：`/root/logs/rev2b-02-question-with-answers.png`

#### P0-2 回答卡片没有评论入口，评论链路完全不存在
- **现象**：回答卡片内无「评论 N」按钮、无评论列表、无输入框；`GET /api/comments?target_type=answer&target_id=2` 实测 200 且有 14 条数据，`POST` 发表也成功（id=325），前端未接入。
- **复现步骤**：`/zhihucopy/question/1` → 回答卡片 → 无任何评论入口，页面滚动到底也没有评论区。
- **期望**：回答底部「评论 N」→ 展开两级评论树 + 输入框，发布后立即出现在列表顶部并 +1。
- **严重度**：P0（阻断主流程）
- **截图**：`/root/logs/rev2b-02-question-with-answers.png`

#### P1-1 顶部搜索被完全忽略：无结果页、无空态，静默展示默认推荐流
- **现象**：输入「代码」回车后 URL 变为 `?q=%E4%BB%A3%E7%A0%81`，但内容区仍是默认推荐流 20 条，标题零命中，无「搜索结果」标题、无命中高亮、无「没有找到」空态。换不可能存在的词「zzzz不存在的词qqqq」结果同样是 20 条推荐流 —— 用户无法判断搜索是否生效。
- **复现步骤**：首页 → 顶部搜索框输入「代码」→ 回车 → 观察 URL 与列表；再搜「zzzz不存在的词qqqq」对比，两者列表一致。
- **期望**：`/?q=` 触发真实检索，标题「"代码" 的相关结果 · N 条」，无结果时给空态 + 推荐关键词；或搜索未上线就不要渲染可提交的搜索框。
- **严重度**：P1
- **截图**：`/root/logs/rev2-08-search.png`、`/root/logs/rev2b-05-search-impossible.png`

#### P1-2 通知页是占位空页，没有列表也没有未读角标
- **现象**：`/notifications` 只剩一句「通知功能将在后续版本上线」，无面包屑返回、无引导按钮；顶部与底部导航均无未读红点/数字（badge 元素=0），「未读数清零」这一步无法验证。
- **复现步骤**：已登录态访问 `/zhihucopy/notifications`（或点移动端底部「通知」）→ 只有一行占位文案。
- **期望**：通知列表（赞同/评论/关注分组）+ 未读高亮 +「全部标为已读」；角标随 `GET /api/notifications/unread-count` 更新，进入页面后清零。后端 `unread-count` 已可用（401 未带 token，带 token 返回 `{"count":0}`）。
- **严重度**：P1
- **截图**：`/root/logs/rev2-07-notifications.png`

#### P1-3 「推荐」tab 实为「最新」，首屏被 e2e/巡检测试数据占满
- **现象**：推荐流前 10 条里 8 条是自动化测试产物：`巡检：一个关于前端性能的问题-mwhx7pwt-24vz？`、`[e2e] q-mwhx6pl5-2g3 — profile 探针问题？`、`[assert] q-mwhv4cxu-2rj?` 等，均带随机后缀、0 回答、1 次浏览。首页代码 `feedQuery()` 对 `recommended` 直接传 `tab=new`，没有排序/过滤。
- **复现步骤**：打开首页（推荐 tab）→ 看前 10 条标题。
- **期望**：推荐流按热度/质量排序，并在服务端过滤 `^\[e2e\]|^\[assert\]|^巡检：` 这类测试数据；冷启动不足时用真实种子内容补齐。
- **严重度**：P1
- **截图**：`/root/logs/rev2b-01-feed-top.png`、`/root/logs/rev2-01-home.png`

#### P2-1 话题胶囊点击无任何反应（不是 404，而是根本没有链接）
- **现象**：问题页「编程」胶囊是 `<span class="tag">`，父元素为 `div`，`cursor:auto`，`href=null`；强制点击后 URL 完全不变。既没有 404 页，也没有任何反馈。
- **复现步骤**：`/zhihucopy/question/1` → 点击标题上方「编程」胶囊 → 页面无变化。
- **期望**：胶囊为 `<Link to="/topic/:id">`，进入话题页（头部名称+简介+关注+讨论数+内容流）。
- **严重度**：P2
- **截图**：`/root/logs/rev2b-03-tag-clicked.png`

#### P2-2 编辑器承诺「支持 Markdown」，正文却按纯文本原样输出
- **现象**：通过接口写入 `**加粗测试** 与 \`inline code\`、- 列表项、> 引用块`，详情页 `.answer__body` 内 `strong/ul/code/blockquote` 数量全为 0，文本原样显示 `**加粗测试**`、`- 列表项一`；`client/package.json` 无任何 markdown 依赖。
- **复现步骤**：以已登录身份在问题页发布含 `**加粗**`、`- 列表` 的回答 → 详情页查看渲染结果。
- **期望**：接入 markdown 渲染（加粗/列表/代码块/引用/链接），或去掉「（支持 Markdown）」的误导文案。
- **严重度**：P2（文案不一致 + 功能缺失）
- **截图**：`/root/logs/rev2b-08-markdown-raw.png`

#### P2-3 问题详情页缺少知乎核心信息层：无作者头像、无「关注问题」、无收藏/分享栏
- **现象**：标题上方只有话题胶囊，标题下方是纯文本作者名+日期+浏览数；没有任何头像、没有关注按钮、回答卡片也没有收藏/分享。与 FEATURES Z903 的排版规格不符。
- **复现步骤**：`/zhihucopy/question/1` 自上而下检查。
- **期望**：作者行含头像+昵称+一句话简介；标题下方「关注问题 / 写回答」；回答底部「赞同 · 评论 · 收藏 · 分享」。
- **严重度**：P2
- **截图**：`/root/logs/rev2b-02-question-with-answers.png`

#### P2-4 时间格式混乱：同一页四种写法且无相对时间
- **现象**：提问显示「提问于 2026/11/14」（`toLocaleDateString`，斜杠日期），回答显示「发布于 2026/11/15 11:26:05」（`toLocaleString`，含秒），热榜无时间，通知无时间；全站无「3 小时前」这类相对时间。
- **复现步骤**：`/zhihucopy/question/1` 对比提问元信息与回答底部时间。
- **期望**：统一「x 分钟前 / x 小时前 / 昨天 / 2026-11-14」，7 天内用相对时间。
- **严重度**：P2（时间单位/格式不一致）
- **截图**：`/root/logs/rev2b-02-question-with-answers.png`

#### P3-1 未登录引导文案有多余空格：「登录 后即可回答这个问题」

- **复现步骤**：退出登录访问 `/zhihucopy/question/1` → 页面底部引导行。
- **期望**：「登录后即可回答这个问题」（去掉空格），或整行可点。
- **严重度**：P3

#### P3-2 搜索框只有回车一条通路，无图标、无提交按钮、无清除

- **复现步骤**：任意页顶部搜索框输入文字 → 观察右侧无任何可点元素。
- **期望**：补放大镜图标与提交按钮，输入后出现清除按钮。
- **严重度**：P3
- **截图**：`/root/logs/rev2-08-search.png`
